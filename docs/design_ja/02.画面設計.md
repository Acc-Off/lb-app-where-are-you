# 画面設計（ワイヤフレーム）

lb-phone の NUI 内に表示されるモバイルサイズ（縦長）UIを前提とする。

---

## 共通仕様

- **底部タブバー**: 2行配置（3列グリッド）
  - 1行目：「地図」「タイムライン」
  - 2行目：「友達」「グループ」「設定」
- **ゴーストモードインジケータ**: ヘッダー右側に常時表示。バッジアイコン+ラベルで status-pill として描画
- **テーマ**: lb-phone のライト/ダークテーマに追従（CSS変数 `--bg-primary`, `--ink-primary` 等）
- **ダイアログ**: フレンド詳細・ブロック確認・削除確認は HTML `<dialog>` 要素を使用（Esc / backdrop クリックで閉じ可能）

## S02 マップ画面 — メイン

```
┌─────────────────────────────┐
│ WhereAreYou?   [● 通常公開] │  ← status-pill（タップでS03）
│ フレンド位置共有              │
├─────────────────────────────┤
│                             │
│  ┌───────────────────────┐  │
│  │        [地図エリア]     │  │  ← Los Santos ローカルタイル
│  │                       │  │
│  │    ● Alice ●           │  │  ← CircleMarker + Tooltip
│  │        ● Bob 👻        │  │  ← フリーズ中はグレー色
│  │    ● Carol 〜          │  │  ← あいまいはスカイブルー色
│  │              ● 自分    │  │  ← オレンジ色のCircleMarker
│  │                       │  │
│  └───────────────────────┘  │
│                    [現在地]  │  ← GPS FABボタン（右下）
├─────────────────────────────┤
│ [地図] [タイムライン]        │  ← 1行目2タブ
│ [友達] [グループ] [設定]    │  ← 2行目3タブ
└─────────────────────────────┘
```

**マーカー仕様**

Leaflet `CircleMarker` + 常時表示 `Tooltip` で実装。アバター画像は未対応。

| 状態 | マーカー色 | Tooltip表示 |
|------|-----------|------------|
| 通常公開 | 緑 `#16a34a` | 名前 ● |
| フリーズ中 | グレー `#6b7280` | 名前 👻 |
| あいまい表示 | スカイブルー `#0ea5e9` | 名前 〜 |
| 緊急オフ | ― | 地図上に非表示 |
| 自分 | オレンジ `#ff7f11` | 「自分」 |

**移動ステータス判定（内部ロジック）**

| 条件 | 表示 |
|------|------|
| speed >= 8.0 | vehicle |
| speed >= 1.2 | walk |
| それ以外 | idle |

**GPS FABボタン**
- マップ右下に固定配置
- タップで自分の現在位置にマップをセンタリング（自動追従はしない）

**ズームコントロール（B-7 修正）**
- Leaflet 標準ズームボタンは右下（`bottomright`）に配置
- 地図フィルタUI（左上オーバーレイ）と位置が重ならないよう `<ZoomControl position="bottomright" />` を明示指定

**地図フィルタUI**
- 表示フィルタ（全員/フレンドのみ/グループ）を地図上部の固定オーバーレイとして表示
- 地図をスクロール・ドラッグしてもフィルタUIは画面上部に残す
- アプリ起動後、最初に地図タブへ入った時は自分位置を中心に初期表示

## S03 ゴーストモード設定パネル — ボトムシート

ヘッダーの status-pill タップで表示。modal-overlay + sheet（下寄せ）で実装。
オーバーレイ部分クリックで閉じる。設定変更は即時反映。

> 現行実装では、緊急オフ切替（全体）とフレンド/グループ向け設定を1枚のシートに統合している。

```
┌─────────────────────────────┐
│         (overlay)            │
├─────────────────────────────┤  ← sheet（下寄せ modal-card）
│ ゴーストモード設定              │
│                             │
│ 全体                         │  ← セクション見出し（ghost-section-label）
│ [通常モード] [自閉モード]      │  ← 横並び2ボタン; active でハイライト
│                             │
│ フレンド                     │  ← セクション見出し
│  フレンド全員 [GPSモード ▼]   │  ← select（normal/freeze/blur）
│                             │
│ グループ                     │  ← セクション見出し（参加中グループあり時のみ）
│  グループA  [GPSモード ▼]     │  ← グループごとに1行
│  グループB  [圏外モード ▼]    │
│                             │
│        [  閉じる  ]          │
└─────────────────────────────┘
```

実装メモ:
- 「全体」の2ボタンは `mode-grid mode-grid-inline` スタイルで横並び; 現在値が `active`（自閉側は `danger active`）
- フレンド・グループは `<select>` ドロップダウン; 変更で即時 API 呼び出し
- グループ未参加時は「グループ」セクション非表示
- 背景オーバーレイクリックで閉じる


## S05 フレンド追加画面

独立画面ではなく、modal-overlay で表示。オーバーレイ部分クリックで閉じる。

```
┌─────────────────────────────┐
│         (overlay)            │
│  ┌───────────────────────┐  │
│  │ フレンドを追加          │  │
│  │                       │  │
│  │ 近くのプレイヤー        │  │
│  │ PlayerNear01 (15m) [申請]│ │
│  │ PlayerNear02 (42m) [申請]│ │
│  │                       │  │
│  │ ID / 名前検索          │  │
│  │ [入力欄      ] [検索]  │  │
│  │                       │  │
│  │ [1] PlayerXYZ    [申請] │  │
│  │ [2] BlockedUser [解除]  │  │
│  │     ↑ブロック中タグ     │  │
│  └───────────────────────┘  │
└─────────────────────────────┘
```

- modal-card 形式で表示（独立画面ではない）
- 近くの候補: 距離(m)表示 + 申請ボタン
- 検索結果: `[serverId] displayName` 形式で表示
- accepted 済みは検索結果から除外
- pending は「申請中」タグ表示（ボタンなし）
- blocked は「解除」ボタン +「ブロック中」タグ表示
- relation = none のみ「申請」ボタン表示

## S06 フレンド詳細ダイアログ

マップのマーカータップ、またはフレンド一覧の「詳細」ボタンで表示。
HTML `<dialog>` 要素で実装。Esc / backdrop クリックで閉じ可能。

```
┌─────────────────────────────┐
│                             │
│  Alice                      │
│  オンライン / 通常公開 / 停車  │
│  関係: フレンド              │
│                             │
│  [フレンド削除]    [ブロック]  │  ← 横並び（flex）
│                             │
│  [        閉じる        ]    │  ← form method="dialog"
│                             │
└─────────────────────────────┘
```

実装メモ:
- `<dialog>` + `showModal()` で表示
- 情報は1行サマリ形式（オンライン状態 / ゴーストモード / 移動ステータス）
- 「フレンド削除」は `danger-outline` スタイル（赤枠赤字）→ S07b 確認へ
- 「ブロック」は通常ボタン → S07 確認へ
- 非フレンド（同一グループのみ可視）の場合は操作ボタンを非表示
- 関係表示は `フレンド` または `グループ（グループ名一覧）`
- 「閉じる」は `<form method="dialog">` による標準クローズ

## S12 グループ画面

ラジオチャンネル型グループの作成・参加・退出。
参加/作成は画面右上の「＋追加」からモーダルで入力する。
グループ名が既存ならパスワード照合して参加、なければ新規作成。
管理操作はない（編集・強制退出・名前変更なし）。メンバー0人で自動解散。

```
┌─────────────────────────────┐
│ グループ                     │
│                    [＋追加]   │
├─────────────────────────────┤
│                             │
│ ┌ 参加中のグループ ─────────┐ │
│ │                           │ │
│ │ 仲良し (3人)       [退出] │ │
│ │  Alice, Bob, +1           │ │
│ │                           │ │
│ │ レース部 (5人)     [退出] │ │
│ │  Charlie, Dave, +3        │ │
│ │                           │ │
│ └───────────────────────────┘ │
│                             │
├─────────────────────────────┤
│ [地図] [タイムライン]        │
│ [友達] [グループ] [設定]    │
└─────────────────────────────┘
```

操作メモ:
- 参加/作成は右上「＋追加」押下でモーダルを開いて実行する
- グループ参加失敗（名前未入力・パスワード誤り等）のエラーはモーダル内にインライン表示する（lb-phone 通知廃止、B-9 対応）
- メンバー名をタップで展開（全員表示）
- 退出は即時（確認ダイアログなし、軽量さ優先）
- 退出失敗時は lb-phone 内ポップアップダイアログで通知（`components.setPopUp`、B-9 対応）
